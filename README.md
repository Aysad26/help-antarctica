# Help Antarctica

Интерактивное путешествие по Антарктике: параллакс, морские животные, погружение под воду и прибытие к полярной станции.

Дизайн и разработка исходного архивного проекта — студия «Веб Анатомия»: https://webanatomy.ru/

[Русская версия](https://aysad26.github.io/help-antarctica/?lang=ru) · [English](https://aysad26.github.io/help-antarctica/?lang=en)

## Файлы проекта

- `docs/` — полная рабочая версия сайта: HTML, CSS, JavaScript, изображения и шрифты. GitHub Pages публикует эту папку из ветки `main`.
- `help-antarctica-v31.tar.gz` — полный базовый архив.
- `help-antarctica-v33.tar.gz` — обновление до версии 33, включая исправление арки, движение животных по скроллу и новые эффекты.
- `help-antarctica-v38.tar.gz` — промежуточное обновление типографики и кнопки первого экрана.
- `help-antarctica-v39.tar.gz` — возвращение Moderustic в заголовки. Крупный текст кнопки в одну строку и прежний кит сохранены.
- `help-antarctica-v40.tar.gz` — новый кит по референсу, исправление обрезки животных на границах сцен и полёт альбатроса за карточками.
- `help-antarctica-v41.tar.gz` — деформация трёх медуз в одном WebGL-контексте с общей текстурой и запасным Canvas 2D.
- `help-antarctica-v45.tar.gz` — все правки версий 42–45: новый кит и брызги, детальная вода, единая гамма льда, чистые кромки льдин и белая пена у кита и косатки.
- `help-antarctica-v46.tar.gz` — заключительная коррекция резкости, переходов воды, контакта льдины пингвинов и пены; приближение при удержании увеличено до 1,15×.
- `help-antarctica-v48.tar.gz` — все правки версий 47–48: стабильные стыки погружения и земли, обновлённый баклан, мобильные позиции тюленя и корабля, бирюзовые значки справок, пена у арки и быстрый зум до 1,25×.
- `help-antarctica-v49.tar.gz` — компактная прямая SVG-буква i с засечками в значках справки.
- `help-antarctica-v50.tar.gz` — буква i уменьшена на 20%, максимум зума 1,15×; синхронная отрисовка надводных эффектов при зуме, стабильная фактура пены и исправлен двойной масштаб корабля.
- `help-antarctica-v51.tar.gz` — переключатель RU / EN без сброса сцены, полный перевод 13 глав и 21 справки, запоминание языка и ещё меньшая буква i.
- `help-antarctica-v52.tar.gz` — отдельная основная кнопка «Поделиться» под финальной карточкой, с иконкой шеринга и адаптацией для коротких экранов.
- `.github/workflows/import-site.yml` — восстановление полной версии сайта из базового архива и обновления.

## Локальный запуск

Сборка не нужна. Запустите из корня репозитория:

```bash
python -m http.server 8000 --directory docs
```

Затем откройте http://localhost:8000/ .

Для дальнейших правок редактируйте файлы в `docs/` и сохраняйте изменения в `main`: Pages обновит сайт автоматически.

## Текущая типографика

Заголовки — Moderustic 600. На первом экране описание и кнопка также используют Moderustic; остальные шрифты интерфейса сохранены. Эксперимент с LINE Seed завершён возвратом к Moderustic.
