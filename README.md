# Help Antarctica

Интерактивное путешествие по Антарктике: параллакс, морские животные, погружение под воду и прибытие к полярной станции.

Дизайн и разработка исходного архивного проекта — студия «Веб Анатомия»: https://webanatomy.ru/

## Файлы проекта

- `docs/` — полная рабочая версия сайта: HTML, CSS, JavaScript, изображения и шрифты. GitHub Pages публикует эту папку из ветки `main`.
- `help-antarctica-v31.tar.gz` — полный базовый архив.
- `help-antarctica-v33.tar.gz` — обновление до версии 33, включая исправление арки, движение животных по скроллу и новые эффекты.
- `.github/workflows/import-site.yml` — восстановление полной версии сайта из базового архива и обновления.

## Локальный запуск

Сборка не нужна. Запустите из корня репозитория:

```bash
python -m http.server 8000 --directory docs
```

Затем откройте http://localhost:8000/ .

Для дальнейших правок редактируйте файлы в `docs/` и сохраняйте изменения в `main`: Pages обновит сайт автоматически.
